# 🚀 Быстрый старт

## Установка и запуск

### 1. Установка зависимостей

```bash
npm install
```

### 2. Создание файла конфигурации

Файл `.env` уже создан со стандартными настройками:
- API URL: `http://localhost:3001/api`
- Название приложения: Баскетбольный клуб

### 3. Запуск бэкенда

Убедитесь, что бэкенд запущен на порту 3001. Из корневой папки проекта:

```bash
cd ../backend
npm install
npm run start:dev
```

### 4. Запуск фронтенда

```bash
npm run dev
```

Откройте браузер по адресу: **http://localhost:3000**

## 🎯 Первые шаги

1. **Регистрация**
   - Перейдите на страницу регистрации
   - Заполните форму (имя, email, пароль)
   - После регистрации вы будете перенаправлены на страницу входа

2. **Вход в систему**
   - Введите email и пароль
   - После входа вы попадёте на главную страницу

3. **Просмотр расписания**
   - Перейдите в раздел "Расписание"
   - Выберите дату
   - Запишитесь на интересующее занятие

4. **Магазин**
   - Перейдите в раздел "Магазин"
   - Выберите товар
   - Купите за зёрна (внутренняя валюта)

5. **Профиль**
   - Просмотрите свой профиль
   - Проверьте расписание на сегодня
   - Посмотрите достижения (если есть)
   - Переведите зёрна другому пользователю

## ❓ Решение проблем

### Не подключается к API
- Проверьте, что бэкенд запущен на порту 3001
- Убедитесь, что в `.env` указан правильный URL

### Ошибка при регистрации
- Проверьте, что бэкенд настроен правильно
- База данных должна быть инициализирована

### Не отображаются данные
- Откройте консоль разработчика (F12)
- Проверьте вкладку Network на наличие ошибок
- Убедитесь, что бэкенд отвечает на запросы
