# Фронтенд баскетбольного клуба

Современный веб-сайт баскетбольного клуба на React + TypeScript + Tailwind CSS.

## 🚀 Возможности

### Страницы

- **Главная страница** - О клубе, секции, новости, команда, партнеры
- **Расписание** - Просмотр занятий по датам, запись на курсы, счетчик абонементов
- **Магазин** - Покупка товаров за внутреннюю валюту (зёрна)
- **Новости** - Лента новостей с изображениями
- **Чаты** - Три вида чатов (Ярмарка, Направления, Поддержка)
- **Профиль** - Информация о пользователе, достижения, расписание на сегодня, перевод зёрен
- **Регистрация/Вход** - Аутентификация пользователей

### Функционал

- ✅ Регистрация и вход в систему
- ✅ Просмотр расписания с возможностью записи на занятия
- ✅ Покупка товаров за внутреннюю валюту
- ✅ Система достижений (общие и по секциям)
- ✅ Чаты в реальном времени
- ✅ Перевод зёрен между пользователями
- ✅ Адаптивный дизайн для всех устройств
- ✅ Современный UI с градиентами и анимациями

## 📦 Установка

1. Установите зависимости:
```bash
npm install
```

2. Запустите проект в режиме разработки:
```bash
npm run dev
```

Приложение откроется по адресу: http://localhost:3000

## 🏗️ Сборка для продакшена

```bash
npm run build
```

Готовые файлы появятся в папке `dist/`

## 🛠️ Технологии

- **React 18** - UI библиотека
- **TypeScript** - Типизация
- **Tailwind CSS** - Стилизация
- **React Router** - Роутинг
- **Axios** - HTTP клиент

- **Vite** - Сборщик

## 🌟 Особенности реализации

1. **Регистрация → Вход**: После регистрации пользователь автоматически перенаправляется на страницу входа
2. **Расписание**: Поддержка параллельных занятий, группировка по времени
3. **Магазин**: Покупка строго по 1 товару за раз
4. **Чаты**: Три отдельных чата с автообновлением
5. **Профиль**: Динамическое отображение достижений (раздел появляется только при наличии достижений)
6. **Новости**: Скролл-лента с поддержкой изображений

## 📱 Адаптивность

- Mobile: < 768px
- Tablet: 768px - 1024px
- Desktop: > 1024px

Все страницы полностью адаптивны и работают на любых устройствах.
