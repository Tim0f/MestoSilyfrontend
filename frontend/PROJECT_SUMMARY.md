## 🚀 Как запустить

### Быстрый старт

```bash
# Установка
npm install

# Запуск
npm run dev
```

**URL:** http://localhost:3000

### Production

```bash
# Сборка
npm run build

# Предпросмотр
npm run preview
```

### Docker

```bash
# Сборка образа
docker build -t basketball-frontend .

# Запуск
docker run -p 80:80 basketball-frontend
```

- **/auth/** - аутентификация
- **/users/** - пользователи
- **/news/** - новости
- **/products/** - товары
- **/sections/** - секции
- **/sessions/** - занятия
- **/chat/** - чаты
- **/grains/** - зёрна
- **/orders/** - заказы

### Аутентификация

- JWT токены в localStorage
- Автоматическое добавление к запросам
