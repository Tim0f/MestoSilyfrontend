# ✨ Функционал фронтенда баскетбольного клуба

## 📄 Реализованные страницы

### 🏠 Главная страница (/)

**Секции:**

1. **Hero Section**
   - Большой заголовок
   - Описание клуба
   - Кнопка "Выбрать секцию"

2. **О нас**
   - 3 карточки с преимуществами:
     - Опытные тренеры
     - Индивидуальный подход
     - Достижения

3. **Наши секции**
   - Показ 4 последних секций
   - Ссылка на полный список

4. **Новости**
   - 3 последние новости
   - Карточки с изображениями
   - Ссылка на все новости

5. **Команда**
   - 6-7 тренеров
   - Фото (placeholder круги)
   - Имя и опыт

6. **Наши друзья и партнеры**
   - 4 карточки партнеров
   - Placeholder иконки

---

### 🛒 Магазин (/shop)

**Функционал:**
- Отображение всех товаров
- Карточки товаров с:
  - Изображением (или placeholder)
  - Названием
  - Описанием
  - Ценой в зёрнах 🌾
  - Количеством в наличии
- Покупка **строго по 1 штуке**
- Показ баланса зёрен пользователя
- Анимация успешной покупки
- Проверка наличия товара

**Требования:**
- ✅ Нужна авторизация для покупки
- ✅ Автоматическое списание зёрен
- ✅ Обновление баланса после покупки

---

### 📅 Расписание (/schedule)

**Функционал:**
- Выбор даты (вперёд/назад)
- Показ **оплаченных посещений** (счётчик вверху)
- Группировка занятий по времени
- **Поддержка параллельных занятий**
- Карточка занятия содержит:
  - Название секции
  - Время начала и окончания
  - Тренера
  - Количество мест (X/Y)
  - Локация (если есть)
- Запись на занятие
- Статусы:
  - Вы записаны (зелёная)
  - Нет мест (серая)
  - Доступно (оранжевая)

**Требования:**
- ✅ Авторизация для записи
- ✅ Скролл по датам
- ✅ Счётчик абонементов

---

### 📰 Новости (/news)

**Функционал:**
- Лента всех новостей
- Карточки новостей с:
  - Главным изображением
  - Заголовком
  - Полным текстом
  - Датой публикации
  - Дополнительными фото (галерея)
- Скролл новостей

**Особенности:**
- 3-5 новостей в месяц (как указано)
- Поддержка multiline текста
- Адаптивная галерея изображений

---

### 💬 Чаты (/chats)

**Три типа чатов:**

1. **Ярмарка** 🛒
   - Обмен/продажа товаров между участниками

2. **Направления** 🏀
   - Обсуждение секций и тренировок

3. **Поддержка** 💬
   - Помощь от администрации

**Функционал:**
- Переключение между чатами (табы)
- История сообщений
- Отправка сообщений
- Автообновление (каждые 3 секунды)
- Отображение:
  - Своих сообщений справа (оранжевые)
  - Чужих сообщений слева (серые)
  - Имени отправителя
  - Времени отправки

**Требования:**
- ✅ Только для авторизованных
- ✅ Real-time обновления

---

### 👤 Профиль (/profile)

**Левая колонка:**

1. **Карточка пользователя**
   - Фото профиля (или аватар с инициалом)
   - Имя
   - Email
   - Дата рождения
   - 🎁 Иконка подарка в день рождения
   - Баланс зёрен 🌾

2. **Перевод зёрен**
   - Форма перевода
   - Выбор получателя (по email)
   - Сумма
   - Проверка баланса

**Правая колонка:**

1. **Расписание на сегодня** 📅
   - Список занятий на текущий день
   - Секция
   - Время
   - Если занятий нет - пустое состояние

2. **Достижения** 🏆
   - **Общие достижения** (желтые)
   - **Достижения по секциям** (оранжевые)
   - **Раздел появляется только если есть достижения**

**Требования:**
- ✅ Только для авторизованных
- ✅ Динамическое отображение достижений
- ✅ Объявление с днём рождения

## ⚙️ Технические особенности

### 🎨 Дизайн
- Оранжевая цветовая схема (#f99f16)
- Градиенты на кнопках и карточках
- Тени и hover-эффекты
- Современный минималистичный UI
- Полная адаптивность (mobile/tablet/desktop)

### 🔒 Авторизация
- JWT токены в localStorage
- Автоматическое добавление к запросам
- Защищённые роуты
- Редирект на login при 401

### 📱 Адаптивность
- Mobile-first подход
- Breakpoints: sm (640px), md (768px), lg (1024px), xl (1280px)
- Все компоненты адаптивны

### ⚡ Производительность
- Vite для быстрой сборки
- Tree-shaking
- Минификация в продакшене
- Оптимизированные изображения (рекомендуется)

### 🛠️ Типизация
- Полная типизация TypeScript
- Интерфейсы для всех данных
- Type-safe API запросы
